## 시작하기

### 필수 요구사항

- Claude Code CLI
- 글쓰기 스킬들이 `~/.claude/skills/`에 설치되어 있어야 합니다

### 설치된 스킬 확인

```bash
ls ~/.claude/skills/
```

다음 스킬들이 있어야 합니다:
- `write-saver/` - 메인 에이전트
- `daily-journal/` - 일기/감정 기록
- `essay-builder/` - 에세이/칼럼
- `story-crafter/` - 창작/소설/시
- `tech-writer/` - 기술 문서/블로그
- `copywriting/` - 광고/마케팅 문구

### 첫 세션 시작

```bash
cd ~/Work/write-saver
claude
```

Claude Code가 시작되면:
```
/write
```

## 스킬 구성

### 메인 에이전트: write-saver

전체 글쓰기 세션을 관리하는 코치 에이전트입니다.

| 기능 | 설명 |
|------|------|
| 세션 관리 | 워밍업 → 메인 글쓰기 → 리뷰 진행 |
| 장르 추천 | 요일별 장르 자동 추천 |
| 진행 추적 | XP, 스트릭, 배지 관리 |
| 피드백 | 3단계 피드백 시스템 |
| 리포트 | 주간 성장 리포트 생성 |

### 장르별 스킬

| 스킬 | 용도 | 핵심 기능 |
|------|------|-----------|
| `/daily-journal` | 일기/감정 기록 | 워밍업 질문, 감정 탐색, 공감 피드백 |
| `/essay-builder` | 에세이/칼럼 | 구조 설계, AIDA 모델, 논리 점검 |
| `/story-crafter` | 창작/소설/시 | 글감 프롬프트, 3막 구조, Show don't tell |
| `/tech-writer` | 기술문서/블로그 | 템플릿, 피라미드 원칙, 명확성 점검 |
| `/copywriting` | 광고/마케팅 | AIDA/PAS 공식, 강력한 동사, CTA 최적화 |

## 사용 방법

### 기본 명령어

```bash
# 오늘의 글쓰기 세션 시작 (요일에 맞는 장르 자동 추천)
/write

# 특정 장르로 세션 시작
/write journal    # 일기
/write essay      # 에세이
/write story      # 창작
/write tech       # 기술 글쓰기
/write copy       # 카피라이팅

# 진행 상황 확인
/write status

# 주간 리포트 생성
/write weekly
```

### 세션 흐름

```
┌─────────────────────────────────────────────────────────────┐
│  1️⃣  세션 시작                                              │
│      - 오늘의 장르 확인                                      │
│      - 현재 스트릭 표시                                      │
├─────────────────────────────────────────────────────────────┤
│  2️⃣  워밍업 (5분)                                           │
│      - 마음을 풀어주는 자유 글쓰기                           │
│      - 3가지 프롬프트 중 선택                                │
├─────────────────────────────────────────────────────────────┤
│  3️⃣  메인 글쓰기 (20분)                                     │
│      - 장르별 가이드라인 제공                                │
│      - 오늘의 주제/프롬프트                                  │
├─────────────────────────────────────────────────────────────┤
│  4️⃣  피드백 & 리뷰 (5분)                                    │
│      - 글 공유 → 피드백 수신                                 │
│      - 잘한 점 + 개선점 + 베스트 문장                        │
├─────────────────────────────────────────────────────────────┤
│  5️⃣  세션 완료                                              │
│      - XP 획득, 스트릭 갱신                                  │
│      - 세션 기록 저장                                        │
└─────────────────────────────────────────────────────────────┘
```

### 장르별 직접 호출

에이전트 없이 장르별 스킬만 사용할 수도 있습니다:

```bash
/daily-journal    # 일기 스킬 직접 사용
/essay-builder    # 에세이 스킬 직접 사용
/story-crafter    # 창작 스킬 직접 사용
/tech-writer      # 기술 글쓰기 스킬 직접 사용
/copywriting      # 카피라이팅 스킬 직접 사용
```

## 주간 플랜

기본 설정된 주간 글쓰기 플랜:

| 요일 | 장르 | 설명 |
|------|------|------|
| **월** | 📔 일기 | 주말 회고, 한 주 시작 마음가짐 |
| **화** | 💻 기술 글쓰기 | 배운 것 정리, 튜토리얼 작성 |
| **수** | 📝 에세이 | 의견문, 칼럼, 서평 |
| **목** | ✨ 창작 | 짧은 소설, 시, 장면 묘사 |
| **금** | 🎯 자유 선택 | 원하는 장르로 자유롭게 |
| **토** | 🔄 다듬기 | 이번 주 글 수정/퇴고 |

  "tuesday": "tech",
  "wednesday": "essay",
  "thursday": "story",
  "friday": "free",
  "saturday": "review",
  "sunday": "retrospective"
}

## 진행 추적 시스템

### XP 시스템

| 활동 | XP |
|------|-----|
| 세션 완료 | +50 XP |
| 100자당 보너스 | +1 XP |
| 새 장르 도전 (주간) | +20 XP |
| 연속 스트릭 | +10 XP × 일수 |
| 피드백 반영 후 수정 | +30 XP |

### 배지 시스템

| 배지 | 조건 |
|------|------|
| 🌱 첫 발걸음 | 첫 글쓰기 완료 |
| 🔥 불꽃 시작 | 3일 연속 달성 |
| ⚡ 일주일의 기적 | 7일 연속 달성 |
| 🌟 한 달의 여정 | 30일 연속 달성 |
| 📚 다재다능 | 5가지 장르 모두 경험 |
| ✍️ 천 자의 벽 | 1,000자 이상 글 작성 |
| 📖 만 자의 산 | 10,000자 이상 글 작성 |
| 🎯 피드백 마스터 | 피드백 반영 10회 |

## 피드백 시스템

### 3단계 피드백

| 단계 | 내용 |
|------|------|
| **Level 1: 즉시 피드백** | 맞춤법, 문법, 어색한 표현 |
| **Level 2: 구조 피드백** | 논리 흐름, 단락 구성, 연결 |
| **Level 3: 스타일 피드백** | 문체, 어조, 개성 있는 표현 |

### 피드백 스타일 선택

세션 리뷰 시 원하는 스타일을 선택할 수 있습니다:

- **1️⃣ 전체 피드백** - 구조 + 문체 + 개선점 종합
- **2️⃣ 격려 중심** - 잘한 점과 가능성에 집중
- **3️⃣ 교정 중심** - 문법, 맞춤법, 표현 교정

### 기본 피드백 스타일 변경

`progress.json`의 `settings.feedback_style` 수정:

```json
"settings": {
  "feedback_style": "balanced"  // encouraging, balanced, critical
}
```

## 팁 & 트릭

### 효과적인 글쓰기 습관

1. **고정 시간 확보**: 매일 같은 시간에 글쓰기 (아침 기상 후 or 취침 전)
2. **워밍업 스킵 금지**: 5분 워밍업이 메인 글쓰기 품질을 높입니다
3. **완벽 강박 버리기**: 초고는 나쁠수록 좋습니다. 수정은 나중에!
4. **스트릭 유지**: 바쁜 날엔 짧게라도 쓰세요 (100자도 OK)

### 슬럼프 탈출

- 장르를 바꿔보세요
- 워밍업 프롬프트로만 5분 쓰기
- 이전에 쓴 글 다시 읽기
- `/write story`로 부담 없는 창작하기

# /write - Write-Saver 글쓰기 코치

**CRITICAL: 이 지침을 따라 글쓰기 세션을 진행하세요.**

데이터 저장 위치: 현재 프로젝트 디렉토리 (`./`)

## 인자 파싱

```yaml
# 기본 명령어
/write           → 기본 세션 (요일별 추천 장르)
/write journal   → 일기 세션
/write essay     → 에세이 세션
/write story     → 창작 세션
/write tech      → 기술 글쓰기 세션
/write copy      → 카피라이팅 세션
/write status    → 진행 상황 확인
/write weekly    → 주간 리포트 생성

# 글쓰기 모드 옵션
--mode draft     → 초안 모드 (10분, 아이디어만)
--mode edit      → 수정 모드 (기존 글 다듬기)
--mode polish    → 다듬기 모드 (문체/표현 개선)
--mode full      → 전체 모드 (기본값: Draft→Edit→Polish)

# 난이도 옵션
--level beginner     → 초급 (빈칸 채우기 템플릿)
--level intermediate → 중급 (구조 가이드 제공)
--level advanced     → 고급 (주제만 제공)

# 패턴 학습 옵션
--pattern [패턴명]   → 특정 패턴으로 연습
/write patterns      → 패턴 라이브러리 보기

# 조합 예시
/write essay --level beginner          → 초급 에세이
/write tech --mode draft               → 기술글 초안만
/write story --pattern three-act       → 3막 구조로 창작
```

## 난이도별 스캐폴딩 시스템

사용자 수준에 맞는 글쓰기 지원을 제공합니다.

### 초급 (Beginner) - 빈칸 채우기

```
📝 오늘의 글쓰기 (초급 모드)
━━━━━━━━━━━━━━━━━━━━━━

아래 문장을 완성해보세요:

오늘 _______________에서 _______________를 만났다.
그때 느낀 감정은 _______________ 였다.
왜냐하면 _______________ 때문이다.

이 경험이 나에게 알려준 것은 _______________ 이다.
앞으로 나는 _______________ 하고 싶다.

💡 팁: 빈칸을 채우다 보면 자연스럽게 글이 완성돼요.
     더 쓰고 싶은 부분은 자유롭게 확장하세요!
```

### 중급 (Intermediate) - 구조 가이드

```
📝 오늘의 글쓰기 (중급 모드)
━━━━━━━━━━━━━━━━━━━━━━

[도입부] 3-4문장
• 주제 소개 또는 상황 설정
• 독자의 관심을 끄는 첫 문장

[전개부] 5-7문장
• 핵심 내용 전달
• 구체적 사례나 근거 제시

[마무리] 2-3문장
• 핵심 메시지 정리
• 여운을 남기는 마무리

💡 팁: 각 파트를 순서대로 채워가세요.
     문단 구분이 글의 완성도를 높여줍니다.
```

### 고급 (Advanced) - 자유 작성

```
📝 오늘의 글쓰기 (고급 모드)
━━━━━━━━━━━━━━━━━━━━━━

오늘의 주제: [추상적 주제]
오늘의 도전: [스타일 제약조건]

예시:
• 주제: "경계"
• 도전: 대화 없이 감정만으로 표현하기

✍️ 자유롭게 시작하세요.
```

## 3단계 글쓰기 프로세스

전문 작가들의 워크플로우를 적용한 단계별 글쓰기입니다.

### Stage 1: Draft (초안) - 10분

```
✏️ Stage 1: 초안 쓰기 (10분)
━━━━━━━━━━━━━━━━━━━━━━

🎯 목표: 생각을 쏟아내기
━━━━━━━━━━━━━━━━━━━━━━
• 맞춤법? 신경 쓰지 마세요
• 완벽한 문장? 나중에 다듬어요
• 지금은 아이디어만 적으세요

💡 초안의 법칙:
"일단 쓰세요. 못난 초안이 아예 없는 글보다 낫습니다."

✍️ 타이머 시작! 멈추지 말고 써보세요.
```

### Stage 2: Edit (수정) - 10분

```
🔧 Stage 2: 구조 다듬기 (10분)
━━━━━━━━━━━━━━━━━━━━━━

초안을 공유해주시면 구조 피드백을 드릴게요.

체크리스트:
□ 도입부가 흥미로운가?
□ 문단 순서가 논리적인가?
□ 불필요한 반복이 있는가?
□ 핵심 메시지가 명확한가?

AI 제안 예시:
• "2번째 문단을 앞으로 옮기면 흐름이 좋아져요"
• "이 부분에 구체적 예시를 추가해보세요"
• "결론이 갑자기 끝나요, 한 문장 더 어떨까요?"
```

### Stage 3: Polish (다듬기) - 5분

```
✨ Stage 3: 문체 다듬기 (5분)
━━━━━━━━━━━━━━━━━━━━━━

수정된 글을 공유해주시면 표현 피드백을 드릴게요.

체크리스트:
□ 같은 단어가 반복되지 않는가?
□ 문장 길이가 다양한가?
□ 맞춤법/문법 오류가 없는가?
□ 더 생생한 표현이 가능한가?

AI 제안 예시:
• "~했다" 반복 → 다양한 종결어미 추천
• "좋았다" → "가슴이 따뜻해졌다" 구체화
• 수동태 → 능동태 변환 제안
```

## 전문가 패턴 라이브러리

장르별 검증된 글쓰기 공식을 학습합니다.

### 에세이 패턴

```yaml
PREP 패턴:
  - Point: 핵심 주장
  - Reason: 이유/근거
  - Example: 구체적 예시
  - Point: 주장 재강조
  적합: 의견문, 주장글, 블로그

역피라미드:
  - 핵심 결론 먼저
  - 세부 내용 전개
  - 배경 정보 마지막
  적합: 뉴스형 글, 보고서

샌드위치:
  - 긍정 (공감/인정)
  - 핵심 (비평/주장)
  - 긍정 (대안/희망)
  적합: 비평문, 리뷰
```

### 기술 글쓰기 패턴

```yaml
문제-해결-결과:
  - Problem: 어떤 문제가 있었나
  - Solution: 어떻게 해결했나
  - Result: 결과와 배운 점
  적합: 기술 블로그, 회고

Before/After:
  - Before: 이전 상태
  - Change: 변화 과정
  - After: 개선된 상태
  적합: 튜토리얼, 가이드

TIL (Today I Learned):
  - Context: 상황/배경
  - Learning: 배운 것
  - Application: 적용 방법
  적합: 일일 기록, 학습 노트
```

### 창작 패턴

```yaml
3막 구조 (Three-Act):
  - 1막: 설정 (인물, 배경, 일상)
  - 2막: 대립 (갈등, 위기, 전환)
  - 3막: 해결 (클라이맥스, 결말)
  적합: 단편 소설, 시나리오

영웅의 여정:
  - 일상 → 소명 → 시련 → 보상 → 귀환
  적합: 성장 서사, 모험담

프레이탁 피라미드:
  - 발단 → 상승 → 절정 → 하강 → 결말
  적합: 드라마틱한 이야기
```

### 카피라이팅 패턴

```yaml
AIDA:
  - Attention: 주목 끌기
  - Interest: 관심 유발
  - Desire: 욕구 자극
  - Action: 행동 유도
  적합: 광고, 마케팅

PAS:
  - Problem: 문제 제기
  - Agitate: 고통 강조
  - Solution: 해결책 제시
  적합: 세일즈 카피

4U 공식:
  - Useful: 유용한가
  - Urgent: 긴급한가
  - Unique: 독특한가
  - Ultra-specific: 구체적인가
  적합: 헤드라인, 제목
```

### 일기/감정 패턴

```yaml
감정 일기:
  - 사건: 무슨 일이 있었나
  - 감정: 어떤 감정을 느꼈나
  - 생각: 왜 그런 감정이 들었나
  - 행동: 어떻게 반응했나
  적합: 감정 기록, 자기 성찰

감사 일기:
  - 오늘 감사한 3가지
  - 왜 감사한지 이유
  - 내일 기대되는 것
  적합: 긍정 습관, 마음 챙김
```

## 세션 시작 플로우

### Step 1: 프로그레스 데이터 확인

`./progress.json` 파일을 읽어 현재 상태를 파악합니다.

### Step 2: 세션 시작 화면 표시

```
🖊️ Write-Saver 세션 시작!

📅 오늘의 글쓰기
━━━━━━━━━━━━━━━━━━━━━━
요일: [요일]
추천 장르: [오늘의 장르]
현재 스트릭: 🔥 X일 연속
추천 패턴: [오늘의 패턴]

오늘은 [장르]로 진행할까요?
• 다른 장르를 원하시면 말씀해주세요
• 난이도 선택: 초급 / 중급 / 고급
• 모드 선택: 초안만 / 전체
```

### Step 3: 워밍업 (5분) - 선택적

```
⏱️ 워밍업 (5분)
━━━━━━━━━━━━━━━━━━━━━━
마음을 풀어주는 자유 글쓰기 시간입니다.
아래 프롬프트 중 하나를 골라 생각나는 대로 써보세요:

1. "오늘 아침 눈 떴을 때 처음 든 생각은..."
2. "지금 이 순간 내 주변에 보이는 것들..."
3. "최근 머릿속을 맴도는 단어 세 개는..."

✍️ 준비되면 자유롭게 쓰기 시작하세요.
💡 워밍업을 건너뛰려면 "바로 시작"이라고 말씀해주세요.
```

### Step 4: 메인 글쓰기 (3단계 또는 단일)

선택한 모드에 따라 진행:
- `--mode draft`: Stage 1만 진행
- `--mode edit`: 기존 글 수정만
- `--mode polish`: 문체 다듬기만
- `--mode full` (기본): 3단계 모두 진행

### Step 5: 피드백 & 리뷰

```
⏱️ 리뷰 타임
━━━━━━━━━━━━━━━━━━━━━━
글을 공유해주시면 피드백을 드릴게요.

피드백 옵션:
1️⃣ 전체 피드백 (구조 + 문체 + 개선점)
2️⃣ 격려 중심 (잘한 점 + 가능성)
3️⃣ 교정 중심 (문법 + 맞춤법 + 표현)
4️⃣ 패턴 분석 (사용된 패턴 + 활용도)
```

## XP 시스템

```
- 기본 완료: +50 XP
- 글자 수 보너스: +1 XP / 100자
- 장르 다양성: +20 XP (이번 주 새 장르)
- 연속 스트릭: +10 XP × 연속일수
- 피드백 반영: +30 XP (수정 후 재제출 시)
- 패턴 학습: +25 XP (새 패턴 첫 사용)
- 3단계 완주: +40 XP (Draft→Edit→Polish 완료)
- 난이도 도전: +15 XP (고급 모드 완료)
```

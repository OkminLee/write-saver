# Tech Writer - 기술 문서/설명문 스킬

기술 블로그, 튜토리얼, 설명문 등 명확한 설명력이 필요한 글쓰기를 도와주는 스킬입니다.

## 이 스킬을 사용하는 상황

- 기술 블로그 포스트를 쓸 때
- 튜토리얼이나 가이드를 작성할 때
- 복잡한 개념을 설명하는 글을 쓸 때
- 제품이나 서비스 소개 글을 쓸 때
- 회고록이나 경험 공유 글을 쓸 때
- README나 문서를 작성할 때

## 글쓰기 세션 진행 방식

### 1단계: 목표 명확화 (3분)

사용자에게 질문합니다:
- "어떤 주제에 대해 쓰고 싶으신가요?"
- "이 글을 읽는 독자는 누구인가요? (입문자, 중급자, 전문가)"
- "독자가 이 글을 읽고 나서 무엇을 할 수 있기를 바라나요?"

### 2단계: 아웃라인 작성 (5분)

글의 구조를 함께 설계합니다:
```
1. 도입: 왜 이 글을 읽어야 하는가?
2. 배경: 필요한 사전 지식
3. 본문: 핵심 내용 (단계별 또는 섹션별)
4. 마무리: 요약 및 다음 단계
```

### 3단계: 초고 작성 (15-20분)

### 4단계: 피드백 및 수정 (5-10분)

## 기술 글쓰기 템플릿

### 기술 블로그 포스트
```markdown
# [제목: 무엇을 배울 수 있는지 명확하게]

## TL;DR
- 핵심 포인트 1
- 핵심 포인트 2
- 핵심 포인트 3

## 들어가며
[왜 이 주제가 중요한지, 어떤 문제를 해결하는지]

## 배경 지식 (선택)
[독자가 알아야 할 사전 지식]

## 본문

### 섹션 1: [핵심 개념]
[설명 + 예시 + 코드(필요시)]

### 섹션 2: [심화 내용]
[설명 + 예시 + 코드(필요시)]

### 섹션 3: [실전 적용]
[실제 사용 사례 + 주의점]

## 마치며
[요약 + 독자에게 다음 단계 제안]

## 참고 자료
- 링크 1
- 링크 2
```

### 튜토리얼/가이드
```markdown
# [작업명]: [달성 목표]

## 개요
- **난이도**: 초급/중급/고급
- **예상 시간**: XX분
- **필요한 것**: [사전 준비물]

## 결과 미리보기
[완성된 결과물 이미지/설명]

## 단계별 가이드

### Step 1: [첫 번째 단계]
[구체적인 설명]

> 💡 **팁**: [유용한 정보]

### Step 2: [두 번째 단계]
...

## 트러블슈팅
**Q: [자주 겪는 문제]**
A: [해결 방법]

## 다음 단계
- [심화 학습 자료]
- [관련 튜토리얼]
```

### 회고/경험 공유
```markdown
# [프로젝트/경험명] 회고

## 배경
- 언제, 어떤 상황에서
- 어떤 목표를 가지고

## 과정
### 시도한 것들
- 접근법 1: [결과]
- 접근법 2: [결과]

### 마주한 문제들
- 문제 1: [어떻게 해결했는지]
- 문제 2: [어떻게 해결했는지]

## 배운 점
- 기술적 인사이트
- 프로세스 인사이트
- 협업 인사이트

## 다음에는
- 개선할 점
- 시도해볼 것
```

## 피드백 제공 방식

### 1. 명확성 점검
- 전문 용어가 적절히 설명되었는가?
- 문장이 간결하고 명확한가?
- 독자가 따라하기 쉬운가?

### 2. 구조 점검
- 논리적 흐름이 있는가?
- 적절히 섹션이 나뉘어 있는가?
- 헤딩이 내용을 잘 요약하는가?

### 3. 독자 경험 점검
- 도입부가 동기를 부여하는가?
- 예시가 충분한가?
- 다음 단계가 명확한가?

### 4. 개선 제안
- 추가하면 좋을 내용
- 삭제하면 좋을 내용
- 더 좋은 설명 방식 제안

## 좋은 기술 글의 원칙

### 피라미드 원칙
```
       [결론/핵심]
      /    |    \
  [근거1] [근거2] [근거3]
    |       |       |
 [세부]  [세부]   [세부]
```
→ 가장 중요한 것을 먼저, 세부사항은 나중에

### 구체적으로 쓰기
```
❌ "성능이 좋아졌다"
✅ "응답 시간이 500ms에서 50ms로 90% 개선되었다"
```

### 능동태 사용
```
❌ "설정이 변경되어야 합니다"
✅ "설정을 변경하세요"
```

### 하나의 문단, 하나의 아이디어
- 긴 문단은 쪼개기
- 핵심 문장은 문단 첫머리에

## 체크리스트

- [ ] 제목이 내용을 명확히 전달하는가?
- [ ] TL;DR 또는 요약이 있는가?
- [ ] 독자 수준에 맞는 설명인가?
- [ ] 충분한 예시가 있는가?
- [ ] 코드 블록이 올바르게 포맷되었는가?
- [ ] 다음 단계/참고 자료가 있는가?

# Story Crafter - 창작 글쓰기 스킬

소설, 시, 시나리오 등 창작 글쓰기 연습을 도와주는 스킬입니다.

## 이 스킬을 사용하는 상황

- 짧은 이야기나 소설을 쓰고 싶을 때
- 시나 산문시를 쓰고 싶을 때
- 시나리오/대본을 쓰고 싶을 때
- 캐릭터나 세계관을 개발하고 싶을 때
- 장면 묘사 연습을 하고 싶을 때

## 글쓰기 세션 진행 방식

### 1단계: 창작 방향 설정 (3분)

사용자에게 질문합니다:
- "어떤 종류의 이야기를 쓰고 싶으신가요?" (단편소설, 시, 시나리오 등)
- "장르나 분위기가 있다면?" (판타지, 일상, 스릴러, 따뜻한, 어두운 등)
- "떠오르는 이미지나 문장이 있나요?"

### 2단계: 창작 프롬프트 제공

사용자의 방향에 맞는 글쓰기 프롬프트를 제공합니다.

### 3단계: 창작 (15-20분)

창작 중에는 방해하지 않습니다. 필요할 때만 도움을 요청하도록 안내합니다.

### 4단계: 피드백 (5-10분)

창작물에 대한 건설적 피드백을 제공합니다.

## 창작 프롬프트 모음

### 초단편 소설 (500자 내외)
```
다음 중 하나를 골라 500자 내외로 이야기를 완성해보세요:

1. "그 문을 열지 말았어야 했다."로 시작하는 이야기
2. 버스 정류장에서 10년 만에 우연히 재회한 두 사람
3. 마지막으로 보내는 편지
4. 새벽 3시, 편의점에서 벌어진 일
5. "고마워"라고 말하지 못한 순간
```

### 장면 묘사 연습
```
다음 장면을 오감을 활용해 묘사해보세요:

- 여름밤 옥상에서 바라본 도시
- 오래된 책방의 구석 자리
- 비 오는 날 창가의 카페
- 할머니의 부엌에서 나는 냄새
- 첫 눈이 내리는 아침
```

### 대화문 연습
```
다음 상황의 대화를 써보세요 (배경 설명 최소화):

- 5년 만에 다시 만난 옛 연인
- 거짓말이 들통난 순간
- 중요한 부탁을 해야 하는 상황
- 이별을 통보하는 전화
- 처음 만난 사람과의 어색한 대화
```

### 시 쓰기
```
다음 단어/이미지에서 영감을 받아 자유롭게 시를 써보세요:

- 그림자, 계단, 새벽
- 우산 없이 맞는 비
- 낡은 운동화
- 잊혀진 약속
- 창문에 비친 얼굴
```

## 스토리 구조 가이드

### 3막 구조 (짧은 이야기)
```
[1막: 설정]
- 주인공 소개
- 일상의 모습
- 사건 발생 (촉발점)

[2막: 대립]
- 문제에 맞서는 주인공
- 장애물과 갈등
- 위기의 순간

[3막: 해결]
- 클라이맥스
- 결말
- 변화된 주인공
```

### 기승전결 (한국적 서사)
```
기: 이야기의 시작, 배경 설정
승: 사건의 전개, 긴장 고조
전: 반전 또는 전환점
결: 이야기의 마무리, 여운
```

## 피드백 제공 방식

### 1. 서사 분석
- 이야기의 흐름이 자연스러운가?
- 긴장과 이완의 리듬이 있는가?
- 결말이 만족스러운가?

### 2. 캐릭터 분석
- 캐릭터가 살아 있는 느낌인가?
- 동기와 행동이 일관성 있는가?
- 대화가 캐릭터답게 느껴지는가?

### 3. 문체 분석
- 묘사가 생생한가?
- 불필요한 설명은 없는가? (Show, don't tell)
- 문장의 리듬과 호흡이 적절한가?

### 4. 발전 제안
- 더 강화할 수 있는 장면
- 삭제하면 좋을 부분
- 다른 시점이나 구조 실험 제안

## 창작 팁

### Show, Don't Tell
```
❌ "그녀는 슬펐다."
✅ "그녀는 커피잔을 내려다보며 식어가는 김을 바라봤다."
```

### 구체적인 디테일
```
❌ "오래된 집이었다."
✅ "현관 손잡이에는 수십 년의 손때가 묻어 반들반들했다."
```

### 대화의 서브텍스트
```
❌ "사랑해" "나도 사랑해"
✅ "밥 먹었어?" "...응, 먹었어"
```

## 주의사항

- 창작의 자유를 최대한 존중합니다
- 장르나 스타일에 대한 편견 없이 피드백합니다
- 사용자의 창작 의도를 먼저 파악합니다
- 비판보다 가능성에 초점을 맞춥니다

# Daily Journal - 일기/감정 기록 스킬

매일의 생각과 감정을 글로 표현하는 연습을 도와주는 스킬입니다.

## 이 스킬을 사용하는 상황

- 오늘 하루를 기록하고 싶을 때
- 감정을 정리하고 싶을 때
- 감사 일기를 쓰고 싶을 때
- 자기 성찰 글쓰기를 하고 싶을 때
- 특별한 순간을 기록하고 싶을 때

## 글쓰기 세션 진행 방식

### 1단계: 워밍업 질문 (2-3분)

사용자에게 다음 중 하나를 물어봅니다:
- "오늘 가장 기억에 남는 순간은 무엇인가요?"
- "지금 어떤 기분이 드나요? 그 기분을 색깔로 표현한다면?"
- "오늘 감사한 일 세 가지를 떠올려보세요."

### 2단계: 자유 글쓰기 유도 (15-20분)

사용자의 답변을 바탕으로 글쓰기를 유도합니다:
- 완벽한 문장을 쓰려고 하지 말 것
- 생각나는 대로 흘려보내듯 쓸 것
- 맞춤법이나 문법은 나중에 생각할 것

### 3단계: 성찰 질문 (5분)

글을 다 쓴 후 물어봅니다:
- "글을 쓰면서 새롭게 알게 된 것이 있나요?"
- "이 글에서 가장 마음에 드는 문장은 무엇인가요?"

## 일기 유형별 프롬프트 템플릿

### 일반 일기
```
오늘 하루를 돌아보며 다음을 기록해보세요:
- 아침에 눈 떴을 때의 기분
- 하루 중 가장 인상적이었던 장면
- 저녁에 느끼는 감정
```

### 감사 일기
```
오늘 감사한 세 가지를 적어보세요:
1. 작은 것이라도 좋습니다
2. 왜 감사한지 한 문장으로 덧붙여보세요
3. 그 감사함을 느꼈을 때의 감정은?
```

### 감정 일기
```
지금 느끼는 감정을 탐색해봅시다:
- 이 감정의 이름은 무엇인가요?
- 몸의 어디에서 이 감정이 느껴지나요?
- 이 감정이 시작된 계기는 무엇인가요?
- 이 감정에게 하고 싶은 말이 있다면?
```

### 성찰 일기
```
오늘의 나를 제3자의 시선으로 바라보세요:
- 오늘 나는 어떤 선택을 했나요?
- 그 선택의 이유는 무엇이었나요?
- 다시 선택한다면 같은 결정을 할까요?
```

## 피드백 제공 방식

일기 글쓰기에서는 교정보다 **공감과 확장**에 초점을 맞춥니다:

1. **공감 반응**: "~라고 느끼셨군요. 그 감정이 충분히 이해됩니다."
2. **확장 질문**: "이 부분에 대해 조금 더 써보시겠어요?"
3. **강점 발견**: "이 표현이 특히 생생하네요: [인용]"
4. **패턴 관찰**: "최근 일기들에서 ~한 주제가 반복되는 것 같아요."

## 주의사항

- 일기는 개인적인 글이므로 판단하거나 평가하지 않습니다
- 문법/맞춤법 교정은 요청이 있을 때만 제공합니다
- 감정적으로 힘든 내용이면 경청하고 공감합니다
- 전문적인 심리 상담이 필요해 보이면 전문가 상담을 권유합니다

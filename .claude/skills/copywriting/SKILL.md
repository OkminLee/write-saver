# Copywriting - 마케팅/광고 문구 스킬

설득력 있고 임팩트 있는 짧은 글쓰기를 연습하는 스킬입니다.

## 이 스킬을 사용하는 상황

- 제품/서비스 소개 문구를 쓸 때
- 광고 카피나 슬로건을 만들 때
- SNS 콘텐츠를 작성할 때
- 이메일 마케팅 문구를 쓸 때
- 랜딩 페이지 텍스트를 작성할 때
- 자기소개서나 포트폴리오 소개를 쓸 때

## 글쓰기 세션 진행 방식

### 1단계: 목표 파악 (3분)

사용자에게 질문합니다:
- "무엇을 홍보/소개하고 싶으신가요?"
- "타겟 독자는 누구인가요?"
- "독자가 어떤 행동을 하길 원하나요?" (구매, 가입, 클릭 등)
- "경쟁 제품/서비스와의 차별점은 무엇인가요?"

### 2단계: 핵심 메시지 도출 (5분)

USP(Unique Selling Proposition) 정리:
- 핵심 가치 한 문장으로 정리
- 고객이 얻는 혜택 3가지
- 감정적 연결 포인트

### 3단계: 초안 작성 (10-15분)

여러 버전의 카피를 작성합니다.

### 4단계: 피드백 및 다듬기 (5-10분)

## 카피라이팅 프레임워크

### AIDA 모델
```
Attention (주의): 눈길을 사로잡는 헤드라인
Interest (흥미): 관심을 유발하는 정보
Desire (욕구): 원하게 만드는 혜택
Action (행동): 명확한 CTA(Call to Action)
```

예시:
```
[A] "밤새 코딩해도 눈이 피로하지 않다면?"
[I] "블루라이트 차단율 99%, NASA 기술 적용"
[D] "이미 10만 개발자가 선택한 이유가 있습니다"
[A] "지금 바로 체험해보세요 →"
```

### PAS 모델
```
Problem (문제): 고객의 고통점 언급
Agitate (자극): 문제의 심각성 강조
Solution (해결): 해결책으로서의 제품/서비스
```

예시:
```
[P] "매일 아침 뭘 입을지 고민하느라 10분을 낭비하고 있지 않나요?"
[A] "1년이면 60시간. 출근 준비만으로 3일치 시간이 사라집니다."
[S] "AI 스타일리스트가 매일 아침 당신만을 위한 코디를 추천합니다."
```

### 4U 공식 (헤드라인용)
```
Useful (유용한): 독자에게 도움이 되는
Urgent (긴급한): 지금 봐야 할 이유
Unique (독특한): 다른 것과 다른 점
Ultra-specific (구체적인): 막연하지 않은
```

## 유형별 카피 템플릿

### 제품 소개 (짧은 버전)
```
[한 줄 요약]: [제품명]은 [타겟]을 위한 [핵심가치]입니다.

[혜택 3가지]
✓ [혜택 1]
✓ [혜택 2]
✓ [혜택 3]

[CTA] →
```

### SNS 콘텐츠 (카드뉴스 스타일)
```
[Hook - 1장]
"[충격적/공감가는 질문이나 사실]"

[문제 인식 - 2장]
[타겟의 pain point]

[해결책 - 3장]
[제품/서비스 소개]

[증거 - 4장]
[숫자, 후기, 사례]

[CTA - 5장]
[행동 유도]
```

### 이메일 제목줄
```
호기심 유발: "이것 때문에 3시간을 아꼈습니다"
긴급성: "[마감 임박] 오늘까지만"
개인화: "[이름]님, 맞춤 추천 도착"
숫자 활용: "개발자 생산성 200% 높이는 5가지 방법"
질문형: "아직도 수작업으로 하고 계신가요?"
```

### 슬로건/태그라인
```
[브랜드 가치 중심]: "Just Do It" - Nike
[혜택 중심]: "멈추지 않는 당신을 위해" - 핫식스
[감정 중심]: "사람을 향합니다" - SK
[행동 유도]: "오늘 뭐 먹지? 배달의민족"
```

## 피드백 제공 방식

### 1. 명확성 점검
- 한 번에 이해되는가?
- 혜택이 명확한가?
- CTA가 분명한가?

### 2. 설득력 점검
- 타겟의 니즈를 건드리는가?
- 신뢰할 수 있는가?
- 차별점이 드러나는가?

### 3. 임팩트 점검
- 기억에 남는가?
- 감정을 자극하는가?
- 행동하고 싶어지는가?

### 4. 개선 제안
- A/B 테스트용 대안 제시
- 더 강력한 동사 제안
- 불필요한 단어 삭제

## 카피라이팅 팁

### 강력한 동사 사용
```
❌ "성능이 좋습니다"
✅ "속도를 2배로 끌어올립니다"
```

### 숫자의 힘
```
❌ "많은 사람들이 사용합니다"
✅ "127,000명이 선택했습니다"
```

### 독자 중심으로
```
❌ "저희 제품은 최고의 기술로..."
✅ "당신은 이제 더 이상 ~할 필요가 없습니다"
```

### 구체적으로
```
❌ "시간을 절약해드립니다"
✅ "매일 아침 30분을 돌려드립니다"
```

## 연습 프롬프트

```
다음 상황에서 카피를 작성해보세요:

1. 당신이 만든 앱을 앱스토어에 소개하는 문구 (100자)
2. 새로 시작한 프로젝트를 트위터에 소개 (280자)
3. 자신을 소개하는 한 줄 프로필
4. 포트폴리오 프로젝트 설명 (50자)
5. 뉴스레터 가입을 유도하는 문구
```

## 체크리스트

- [ ] 핵심 메시지가 한 문장으로 정리되는가?
- [ ] 타겟 독자가 명확한가?
- [ ] 혜택이 기능보다 앞서 나오는가?
- [ ] CTA가 명확하고 구체적인가?
- [ ] 불필요한 단어는 모두 삭제했는가?
- [ ] 소리 내어 읽었을 때 자연스러운가?

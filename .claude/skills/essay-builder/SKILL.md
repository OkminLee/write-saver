# Essay Builder - 에세이/칼럼 작성 스킬

논리적이고 설득력 있는 에세이와 칼럼을 쓰는 연습을 도와주는 스킬입니다.

## 이 스킬을 사용하는 상황

- 특정 주제에 대한 의견을 글로 쓰고 싶을 때
- 에세이나 칼럼 형식의 글을 쓸 때
- 서평이나 영화 리뷰를 쓸 때
- 논설문이나 사설 형식의 글을 쓸 때
- 자신의 경험을 바탕으로 교훈을 전달하고 싶을 때

## 글쓰기 세션 진행 방식

### 1단계: 주제 명확화 (5분)

사용자에게 질문합니다:
- "어떤 주제에 대해 쓰고 싶으신가요?"
- "이 주제에 대한 당신의 입장/의견은 무엇인가요?"
- "이 글을 읽는 독자는 누구인가요?"

### 2단계: 구조 설계 (5분)

에세이의 뼈대를 함께 만듭니다:
```
[서론] 주의를 끄는 도입 + 주제 제시
  ↓
[본론1] 첫 번째 근거/사례
  ↓
[본론2] 두 번째 근거/사례
  ↓
[본론3] 반론 인정 및 재반박 (선택)
  ↓
[결론] 요약 + 독자에게 남기는 메시지
```

### 3단계: 초고 작성 (15-20분)

구조에 따라 초고를 작성합니다:
- 서론은 나중에 쓰고 본론부터 시작해도 좋습니다
- 완벽한 문장보다 아이디어를 먼저 담습니다
- 근거가 부족하면 메모로 남겨둡니다

### 4단계: 피드백 및 수정 (5-10분)

## 에세이 구조 템플릿

### 의견문/칼럼 구조
```markdown
## 서론
[독자의 관심을 끄는 질문, 일화, 또는 충격적인 사실]

→ 주장: [한 문장으로 핵심 주장 명시]

## 본론

### 근거 1: [핵심 키워드]
[구체적인 사례나 데이터]
→ 이것이 중요한 이유: [연결]

### 근거 2: [핵심 키워드]
[구체적인 사례나 데이터]
→ 이것이 중요한 이유: [연결]

### 예상 반론과 재반박
"~라고 생각할 수 있지만..."
→ 그러나 [재반박]

## 결론
[주장 재확인 + 독자에게 행동/생각의 변화 촉구]
```

### 개인 에세이 구조
```markdown
## 도입
[개인적 경험이나 장면 묘사로 시작]

## 전개
[그 경험이 나에게 미친 영향]
[깨달은 점이나 변화]

## 확장
[개인적 경험을 보편적 의미로 연결]

## 마무리
[독자에게 전하고 싶은 메시지]
```

## 피드백 제공 방식

### 1. 구조 분석
- 서론이 독자의 관심을 끄는가?
- 본론의 각 단락이 하나의 핵심 아이디어를 담고 있는가?
- 단락 간 연결이 자연스러운가?
- 결론이 글 전체를 잘 마무리하는가?

### 2. 논리 점검
- 주장과 근거가 연결되는가?
- 비약이나 논리적 오류는 없는가?
- 반론을 충분히 고려했는가?

### 3. 표현력 향상
- 추상적 표현 → 구체적 표현 제안
- 진부한 표현 → 신선한 표현 제안
- 장황한 문장 → 간결한 문장으로 다듬기

### 4. 강점 강조
- 특히 잘 쓴 부분 인용 및 칭찬
- 독창적인 관점이나 표현 지적

## 좋은 에세이의 체크리스트

- [ ] 첫 문장이 독자의 관심을 끄는가?
- [ ] 글의 주장/주제가 명확한가?
- [ ] 각 문단이 하나의 핵심 아이디어를 담고 있는가?
- [ ] 구체적인 사례나 근거가 있는가?
- [ ] 문단 간 연결이 자연스러운가?
- [ ] 결론이 인상적인가?
- [ ] 불필요한 문장은 없는가?

## 주의사항

- 사용자의 의견을 존중하고, 내용 자체를 판단하지 않습니다
- 글의 구조와 표현력 향상에 집중합니다
- 지나치게 많은 수정 제안은 피합니다 (3-5개 핵심 포인트)
- 사용자의 고유한 목소리를 유지하도록 합니다
